# 知识库（客户端资料目录）

- 状态：原型已实现。入口 `index.html#knowledge`（知识与研究 → 知识库），独立页 `pages/knowledge.html`。
- 主实现：`src/pages/knowledge.js`、`knowledge.css`、`src/data.js` 的 `BaigeData.knowledgeDirectory`。共享文件表用 `src/secret-file-list.js`、`secret-file-list.css`。
- 版本基线：2026-11-17，`c7b7c22`。用户决定与完整数据交接见 `docs/知识库与百舸文库需求交接.md` 第 2、5 节。

## 范围与默认界面

- 资料索引包含行业库、企业库、部门库和个人文档。公共目录的对象是库，个人页签直接展示用户自己的文件；公共库内部文档列表和独立知识问答页待接入。点击任何公共库提示已选中的库和独立问答页待接入。
- 行业默认选中，四个页签初始数量依次 4、5、8、2。`#industry`、`#enterprise`、`#department`、`#personal` 可在独立页指定分类；切分类更新 iframe 页内哈希。控制台同模块 iframe 留存，完整刷新恢复初始页面数据。
- `industryBases` 是直接数组；`enterpriseGroups`、`departmentGroups` 为 `{id,name,bases}` 组织分组，默认展开。公共库 `{id,name,owner,time,description?,tone?}`，时间和创建人来自演示元数据。库卡显示蓝色文件夹、名称、创建人、底部分隔线和秒级时间，多分类搜索补充归属；常规三列、宽屏四列、窄桌面两列、更窄单列。公共卡片无分页。

## 搜索与筛选

- 关键字显式提交或回车，trim 后大小写不敏感子串匹配。库匹配名称、创建人、简介、归属组织；个人匹配文件名、类型。搜索匹配的是元数据。
- 默认「当前分类」，企业和部门搜索遵守当前组织下拉选择。「全部分类」且关键词非空时忽略原企业、部门筛选，先公共库卡片后个人文件表。空关键词恢复当前分类。个人的文档/表格/演示/图片/其他类型筛选只影响个人文件。
- 搜索数另计，页签的选中项和总数保留；换页签清搜索并回第一页，分类筛选及折叠状态保留。「清除搜索」保留筛选，「清空筛选」恢复默认范围、全部组织/类型、分组展开。个人表默认 10 条／页，可选 20、50。页签支持方向键及 Home/End，操作弹窗关后归还焦点。

## 个人文档的状态与动作

- 页面内存 `personalDocs` 为 `{id,name,type,created,status}`，种子一份已通过和一份涉密可疑。当前页无上传入口、无账号绑定、原件、持久化或后台联动。
- 表列为文件名、上传时间、文档状态、操作。时间显示到分钟，悬停可看完整时间。状态旁小眼睛在有记录时打开涉密详情，仅显示演示状态提示。共享状态全集为 `detecting / passed / hit / submitted / approved / stored / rejected / failed`，缺省展示另见共享表。个人页未实现这些状态之间的检测、审核和入库迁移。
- `passed / approved / stored` 才能打开正文入口，实际为「文档正文待接入」。页面下载一律禁用，已通过项提示原件未接入，其余提示需先核查通过。
- 点文件名编辑名称或资料类型，名称 trim 后不能为空，输入最多 80 字。保留 ID、时间、状态，重新过滤和分页。删除确认含文件名，确认后只从内存移除。元数据编辑和删除允许对核查未通过记录操作。

## 权限与模块边界

- 入口使用统一平台功能授权；此页未按个人或组织数据授权过滤卡片。个人中心旧「权限申请」可提交部门库数据项 `d:<kbId>`，该审批结果保留在申请记录中，当前写入实际访问授权的是功能项；知识库数据项未联动目录、下载或问答。定位 `src/permission-store.js`、`src/permission-center.js`、`src/pages/permission-review.js`。
- `BaigeData.knowledgeBases` 是首页、百舸问答和悬浮助手沿用的八项知识问答来源，和本目录分开维护；个人文件不在问答选择器。两个目录曾复用 `industry-standard`，显示名不同，跨环境映射需依据生产 ID。百舸文库的文档、百舸写作的素材与这里分别存储。
- 生产衔接待确认库内文件与版本、目录归属、查询/预览/下载/问答 ACL、个人文档生命周期。数据摆渡原型现在已存在，采用另一个演示目录，不与此页互写，见 [数据摆渡](data-transfer.md)。
