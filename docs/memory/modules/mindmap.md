# 思维导图生成 `mindmap`

## 入口和输入

- 智能工具「研究辅助 → 思维导图生成」，首页和热门卡也可打开。白色双栏工作区，左栏三页签「描述主题」「上传文档」「输入大纲」共用栏宽，初始描述主题。各页签保留自己的输入，切换页签不清除其他文本。
- 主题与大纲可点各自示例直接生成。替换有变化输入时提示确认。主题本地按主题词选演示大纲；大纲支持纯文本缩进及 Markdown 标题和列表，首行作标题、层级由缩进或标题等级保存。文档模式可依据已通过正文生成大纲，保留 Markdown 章节；普通正文按文件名及本地正文片段整理。
- 生成期间禁用切输入方式及重复生成，右侧先渐进显示分层大纲，再出彩色可滚动画布。可修改 Markdown 大纲、重新生成、导出 PNG 和打开历史。结果 SVG 基于树形数据绘制，输出 PNG 在浏览器完成。

## 上传和审核

- 上传 TXT／MD／PDF／DOC／DOCX／XLS／XLSX，复用 [前台文件列表与读取](file-audit.md)，有文件名搜索、通过后选用、预览及下载、删除确认、状态小眼睛。新增成功后出现带核查状态的录入须知，5 秒后自动关闭，可手动关闭，核查继续。通过后自动选中该新文件，由用户点生成。
- 导图文档单独保存在 `baige.mindmap.documents.v1`；通过 `createFileAuditStore` 的阶段时间恢复，切回、刷新或同源 storage 事件更新。检测中、可疑、审核中、驳回或失败只向工具公布元信息，不开放选用、正文及下载。可疑可送人工演示通过/驳回，内部 `passed + auditedAt` 映射「审核通过」。
- 已通过的本地原件用 IndexedDB 键 `mindmap:<id>`；异步读取前后核对状态与记录，缺失显示明确提示。两项内置 Markdown 样例能直接选用、预览和下载，移除样例仅影响当前工作区。真实文档移除元数据及原件缓存。

## 结果与历史

- `baige.mindmap.v1` 独立保存历史，含记录 ID、标题、来源页签、输入摘要、大纲、节点数、时间及已核查标记。最多 30 项，同标题更新，支持标题/输入检索、6 项一页、载入、删除。历史中的旧上传项缺少通过标记时须重新上传。打开编辑器保存时更新当前结果的大纲和历史。
- 通过页签缓存保留当前未生成输入及画布；关闭/刷新时未提交输入或未应用的大纲变动参与未保存提醒。文件审核和已保存的生成历史可以跨刷新恢复。主题生成、人工和关键词核查为演示。
