# 纠错校对 `proofread`

## 入口和选文件

- 智能工具「纠错校对」默认文件列表。白色圆角工作区提供「粘贴或输入文字」「上传本地文件」两个并列入口，列表与百舸写作素材共用 [涉密文件列表](file-audit.md)。文件名／上传时间／文档状态／操作，眼睛为核查详情。搜索按按钮或 Enter 提交，与全部／可校对／涉密核查／已完成筛选叠加。已存在结果时列表从该文件直接看结果，无历史记录侧栏。
- 上传 TXT、MD、PDF、DOC/DOCX、XLS/XLSX，先在浏览器提取正文再录入检测。扫描 PDF 无正文提示走 OCR。读取失败有失败行和原因；上传成功保存原件缓存。上传单独完成核查后，点击文件名可选范围开始校对，或通过查看图标先预览全文、再从预览发起。
- 文字入口是独立文本页，有可选名称、可粘贴或编辑的文本及字数，提交前只占工具内存，无草稿已保存提示。发起后先确认至少一项范围（错别字、标点、语法，默认全选），载入原文快照和任务并返回文件列表等待。标题为空时取文件名或正文首行。
- 上传或文字提交显示录入须知，5 秒倒计时自动关闭，也可手关。检测持续；文字任务原文通过才自动开始校对。仍在文件列表且工具可见、相关弹窗已关时自动进入工作区。离开或刷新后从列表恢复进度和结果。涉密可疑从详情提交人工，原型可模拟通过／驳回。核查失败无正文预览。

## 处理、确认和下载

- 处理中与结果统一为左侧文档预览、右侧校对结果两栏，上方有独立顶栏及返回列表。进度可停止。原文快照的字符位置保持稳定，建议按错别字／标点／语法分组，显示原词、替换和错误类型；点原文标记定位建议。采纳即时改变只读正文，不采纳保留原词，两种决定都可撤回，支持批量处理剩余建议。
- 未确认的决定存在 `decisionDraft`。撤回到初始状态清除未保存标记。返回列表、关闭工具标签或刷新触发适用的放弃提示。切换工具页签仍可回来继续。编辑录入页的文字也参加未保存检查。
- 「确认」与首次下载都先询问是否保存和锁定，展示已采纳／不采纳／未处理数。未处理建议保留原文。确认把选择和具体正文一次持久化为 `review.output`，随后再次涉密核查，确认后锁定全部决定。结果检测中／可疑／审核中／驳回在原文件行反映，并有独立结果核查详情。
- 首次下载可在当前结果页等待通过并自动下载；返回、离开该工具或重开后由用户手动打开已通过的结果下载。已确认且通过时直接下载 TXT。原文件从文件列表下载，优先已缓存的原始文件，失去缓存则明确下载提取的 TXT。删除须确认并同时移除对应审校记录及尝试移除原件缓存。

## 持久化和验收

- `baige.proofread.v1` 存储 `records/history`，文件 ID 和任务 `reviewId` 分离，后续业务通过 `review.output` 跟踪结果核查。阶段时间用于刷新续跑，原文检测约 2.6 秒、演示审校约 3 秒。新发起同文件已有记录时不会再创建第二轮，旧种子/旧记录兼容原文位置恢复。原件 IndexedDB 键前缀为 `proofread:`。
- `src/proofread-tool.js`、`src/proofread-store.js`、`src/proofread-{file,office,pdf}.js`、`proofread-tool.css`、`pages/smart-tools.html`。关键词和纠错词表为本地演示，真实后端文件和审校服务待接入。
- `tests/proofread-tool.test.cjs`、`tests/proofread-final-store.test.cjs`、`tests/proofread-office.test.cjs`、`tests/proofread-pdf.test.cjs`。回归两条录入链路、倒计时/关闭、刷新及切工具、原文与结果核查门禁、撤回、未经确认下载、结果锁定和删除。
