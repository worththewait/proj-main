# 高质量数据集 `datasets`

## 浏览与路由

- 控制台和首页目录聚合为一个入口 `datasets`（`pages/datasets.html`），侧栏不展开数据集子项；列表以八张卡片代理同一路由内子项。八类为船海产业、船舶领域标准、船舶行业质量、科技成果、科技文献、文化传播、教育培训、试验测试。各项目文案、资源示例、摘要、更新时间和联系人字段由 `src/datasets-data.js` 提供，不要将样本联系方式复制进记忆。
- `src/pages/datasets.js` 列表 → 详情（真实子路由名，支持直接打开或浏览器回退）以标题、摘要、更新时间和分节内容呈现；未知名称回列表。回列表恢复原滚动与卡片焦点。同一路由重复激活保留滚动状态。

## 申请数据集

- 详情按钮打开申请，重置旧输入；带目标数据集。必填申请事由、至少一个使用范围、起止日期、姓名、单位、联系方式（手机/座机/邮箱校验），另有选填范围补充。开始和结束日期最小值默认今天，结束不能早于开始；修改开始会清理不合法的结束。如有错误聚焦首个错误项。
- 提交时锁按钮并构造数据集 id/name、原因、范围、日期、申请人及 `appliedAt`；存在 `window.BaigeRequestDatasetAccess` 就委派，默认延时后显示成功，没有服务器授权或持久化队列。请求序号防止关闭旧弹窗后串到新表单，失败可重试，离开页面关闭对话框。这个申请不是普通功能开通或 IAM 审批。

## 验收

`tests/datasets-data.test.cjs`、`tests/feature-directory.test.cjs`。复核八项与路由命名一致、返回恢复、日期和联系方式校验、取消后迟到请求不影响新对话。
