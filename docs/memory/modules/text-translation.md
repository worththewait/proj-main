# 文本翻译 `text-translation`

## 输入和输出

- 智能工具「文本翻译」及首页同名入口。白色圆角工作区顶部两种语言下拉，中间交换按钮，下方双栏原文与只读译文。默认中文 → 英文，可选中文、英文、日文、韩文、俄文。交换仅更新语言。保留键盘复制粘贴提示，主按钮「开始翻译」全宽。
- 空输入提示先录入；翻译会临时锁定主按钮并约 420ms 后填入结果。按目标语从本地词表匹配常见短句与问候，尝试不区分大小写匹配；未命中回显输入并显示只在演示环境发生的说明。没有模型、上传、涉密状态或对外请求。

## 历史与会话

- 成功触发结果后记录语言方向、原文、译文和本地日期时间。页内「最近翻译」显示最近 10 条，历史弹窗按原文与译文关键词及起止日期筛选，可查询/重置。每页 5 条，有上一页／下一页，源语为空的历史项用破折号代替。初始 33 条演示记录。
- 切工具保留当前已挂载工作区和内存记录，刷新重新加载演示记录。离开工具关闭历史弹窗并清理翻译定时器；已触发但尚未出结果的翻译可能停在「翻译中」（`deactivate` 尚未恢复按钮状态）。同页重新挂载可能重置输入和结果 DOM。

## 代码和验收

`src/text-translate-tool.js`、`text-translate-tool.css`、`pages/smart-tools.html`。另见 [文档翻译](document-translation.md)。
