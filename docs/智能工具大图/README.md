# 智能工具 · 功能大图

- 画布 **720 × 380**（比例 1.89，与热门工具卡一致），导出 PNG 为 **1440 × 760**。
- 三套配色按工具分类：文档处理 `#245BFF`、写作创作 `#6D5EF7`、研究辅助 `#078B98`，统一深色渐变底、玻璃质感卡片与细线连接。
- `01 文档翻译`、`03 OCR识别`、`09 思维导图生成` 是项目原有配图（源文件仍在 `assets/`，这里做了归档）；其余七张按同一视觉语言新绘。
- `SVG/` 为可编辑源文件，`PNG/` 为导出成品，`00-总览.png` 供核对。
- 使用方式：后台「界面管理 → 功能展示 → 热门工具大图」单张上传即可；也可直接作为功能卡片、汇报材料的配图。
