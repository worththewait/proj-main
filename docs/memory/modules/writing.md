# 百舸写作

- 状态：客户端模板写作、素材库与本地导出的可操作原型。入口 `index.html#writing`（知识与研究 → 百舸写作），独立页 `pages/writing.html`。
- 主实现：`src/pages/writing.js`、`src/writing-store.js`、`writing.css`、`src/secret-file-list.js`、`secret-file-list.css`、`src/local-file-cache.js`。代码基线 2026-11-17，`c7b7c22`。

## 模板入口和写作配置

- 默认个人模板页签，两项为宣贯会工作方案、故事编写；公共三项为科技报告模板、专题研究报告、年度工作总结。卡片显示模式和简介，可「大纲预览」或「使用模板」。个人使用进入大纲编辑；公共使用进入带大纲侧栏和写作历史的三步向导。卡片的「大纲预览」均进入大纲编辑共用界面。
- 大纲从模板克隆；章节记录 `id/title/type/generate/requirements/children`，支持新增一级或子章节、改标题/要求、选择章节或不计入编号的「非章节」、是否需要生成、确认删除章节及子节点。标题必填且最多 80 字，写作要求最多 1000 字。普通子章节按层级编号。编辑当前大纲不会写回模板种子。
- 个人路径「大纲编辑 → 开始写作 → 新建写作」：填写最多 100 字的非空场景（也作生成标题），个人库、企业库、联网来源开关默认开启，可勾选素材，附加项默认关。素材可以不选。个人库、企业库、联网开关供演示展示。
- 公共向导为「输入文章标题 → 选择素材 → 选择工具」，标题 trim 后必填、最多 100 字。必须选「使用知识库作为参考」或最少一份可用素材才允许下一步及提交。前后步保留标题、选择和附加项。两种写作流程均从素材管理挑选已经核查通过的文件，不在配置中上传或审核。
- 三个附加项界面显示「生成绪论／全文总结／参考文献」；内部前者以 `extras.conclusion` 写入结论块，全文总结生成总结块，参考文献选项用于结构提示，参考资料展示使用已选来源/文件名。调整写作输出时应检查标签与实际生成语义。

## 素材管理、检测和原文件

- 唯一上传入口在模板页右上「素材管理」，列表采用共享列「文件名、上传时间、文档状态、操作」，正文查看、下载、删除用居中的线性图标。状态旁眼睛展示涉密详情，即使正文受限也可查流转。无文件类型小图标。搜索用文件名且显式「搜索」或回车提交，清空输入即清关键词。默认全部，另有可选用和涉密核查，计数独立，倒序显示；检测状态刷新保留筛选，成功上传后清筛选显示新文件。
- 使用浏览器文件多选，支持 PDF、Word（.doc/.docx）、PPT（.ppt/.pptx），逐文件最多 200 MiB；一批发现格式/大小不合格则拒绝该批。素材库最多 5 个（含种子和未通过记录），剩余空间不足时只收可容纳数量并提示。
- 元数据记录初始 `detecting + unparsed`。900 ms 后按文件名模拟命中「机密、秘密、涉密、内部、敏感」。干净文件进入 `passed + parsing`，约再 1200 ms 后为 `passed + parsed`；命中为 `hit + unparsed`，只有用户继续提交才变 `submitted`，也可取消上传而删除。在涉密详情展示文件名、状态、解析状态、上传/更新时间、命中词与流转。驳回或失败可打开重新上传；当前入口也受 5 个上限，不会自动移除旧记录。
- 核查状态 `passed/approved/stored` 才可选为素材或打开正文/下载；当前可用性按核查状态，允许解析期间的 `passed`。解析失败的已通过旧记录规范为 `failed`。提交人工审批在本原型只写状态，素材页没有实际审核员工作台或检测任务服务；存储接口 `reviewUpload` 可演示通过或驳回结果。计时依赖页面存活。
- 文件元数据与文档储存在 `localStorage/baige.writing.v1`，含模板、素材和生成历史，写入通知 `baige:writing-store`。真实上传的本地原件走 IndexedDB `baige-local-files` 的 `files` store，键 `writing:<upload.id>`，素材删除/取消同时尝试清理缓存与勾选。浏览器存储不足或演示种子会有缺原件提示。PDF/Word 尝试用 `BaigeProofreadFile.read` 提取可读文本，PPT 可下载以本地查看；异步读取完成后二次校验当前审核状态。此处缓存、演示的文件名检测和文本提取不等同服务器入库或真实内容审核。

## 文档工作区、历史和导出

- 生成当前文档并保存标题、模板、场景、来源、素材显示名、附加选项、章节块和大纲。左大纲、中正文、右侧写作思路/AI 工具。正文根据章节要求拼装固定演示段落，来源与素材名用于提示，不将原件内容喂给模型。AI 优化、扩展、润色当前为提示占位。
- 可返回模板、回大纲编辑或导出，导出是 UTF-8 TXT（标题和章节要求），素材列表的下载是原文件，两者各走自己的入口。公共向导「历史记录」列标题、时间、模板、节数，当前是只读记录，未提供恢复编辑历史输出。
- 各模块的文件数据分别维护：写作素材与客户端知识库个人文档、百舸文库后台和智能工具文件记录不互写。与共用涉密规范的关系见 [涉密文件列表](file-audit.md) 和 `DESIGN.md`。
