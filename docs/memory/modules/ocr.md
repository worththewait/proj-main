# OCR 识别 `ocr`

## 工作区

- 智能工具「OCR识别」、首页入口及热门工具卡。三栏依次为文件、文档预览和解析结果。左栏文件名实时搜索、独立原文件下载图标及上传入口；中栏空态支持拖放/点击。允许多件 PDF、DOC、DOCX、XLS、XLSX、PNG、JPG/JPEG，每份不超过 100 MB。文件列表以扩展名区分文档、图像、表格，可选记录看预览；状态旁眼睛看核查。
- 选中未通过的项只提供提醒和涉密详情，正文和所有解析结果始终受门禁。上传可读 PDF、Word、Excel 走共用正文读取和文件名/正文关键词核查；图片及无可提取文字层的 PDF 自动转人工，疑似命中可从详情手动送审。空文档/读取失败进入失败，人工驳回清理原件和已提取正文。通过后才开放原件预览并自动演示解析。
- 上传的无文字层 PDF 和图片在通过后可用对象 URL 预览，提取到的文档正文用纯文字渲染，示例使用虚构正文。解析约 1.2 秒后提供本地示例结果。中栏缩放按钮目前提示待接入，原始页码和预览表现按介质不同。

## 下载和解析结果

- 左栏「下载原文件」打开独立弹窗，列出全部记录；只有已通过且有原件的条目可勾选，其他显示状态或「暂无原件」。支持全选可下载项、部分选中、计数、取消/确认，退出再打开重置选择。确认时重新核对门禁；选 1 件下载原件，选多件生成一个 `OCR原文件.zip`，重名安全改名，保留文件内容。
- 右栏八种标签为 Markdown、JSON、内容、表格、图表、公式、图片、页眉页脚。切签自动滚入可视，Markdown 可切渲染或原文。「下载解析结果」只对已完成记录可用，JSON 标签导出 JSON，其余导出 Markdown。复制取 Markdown 标签的 Markdown，其他标签的 JSON；「保存」当前为已保存到个人空间的演示提示。解析失败仍可下载通过核查的原件。
- 状态和上传对象在当前智能工具页面内存，刷新恢复种子。演示原件从 `src/ocr-sample-files.js` 的实际样例字节构造，下载弹窗显示实际列表记录。离开关闭下载/核查弹窗，清理预览对象 URL。真实 OCR 引擎、个人空间写入及保密服务待接入。
