01

标志

标志是视觉整体的重要表达，它传达了对百舸的独特认知；品牌色全部提取自标志本身。

Logo

1.1 标志构成

百舸标志由两部分组成：帆形图形与「百舸」字标。帆形取「百舸争流」之意，由三片风帆沿对角线依次展开， 前帆使用品牌蓝 → 智能紫渐变，字标使用海军蓝；图形与文字可组合使用， 也可在极小尺寸或已有品牌语境（如顶栏）中单独使用帆形。标志文件使用透明底 PNG / SVG，不得重绘或描边。

字标采用加粗黑体，与帆形底边对齐；图形与文字的比例关系见下页，不得增减间距或改变字重。

1.2 比例规范

标志的尺寸体系以帆形高度 = 1X 为基准单位。标志总宽约 2.7X，帆形宽 0.9X，帆形与字标间距 0.3X，字标宽 1.5X、字高 0.66X。 缩放标志时必须整组等比缩放，任何场景下不得单独调整图形与文字的比例或间距。

1.3 保护空间与最小尺寸

品牌标志四周必须预留最小保护空间 0.25X（X = 帆形高度），以防止视觉冲击力受到影响； 保护空间内不得放置任何其它图形元素、文字、图片或界面边缘。 屏幕端标志高度不小于 24px（页脚、水印等次要场景）；顶栏等主要场景使用 34px； 印刷品上标志高度不小于 8mm。

错误用法

另需避免：旋转标志、为其添加描边或描边字、放在低对比度或高饱和底色上、将帆形单独放大裁切作背景。 深色背景使用时须确认帆形渐变完整可见，必要时改用单色反白版本。

1.4 品牌主色提取 · 标志即色板

规范中的品牌色直接提取自标志：对标志文件逐像素采样后，帆形渐变、字标分别对应四组色值， 再按界面可读性要求校正为设计令牌。这样做的目的：让用户看到的品牌（标志）与用到的品牌（按钮、链接、选中态）同源， 颜色即品牌记忆，操作认知与视觉认知互相强化，不需要用户学习第二套色彩语言。

02

设计原则

颜色按角色分配，层级靠留白与边框建立，强色只留给操作与状态。

Principles

首页承载「认识平台」与「开始工作」两件事：上方是品牌与技术感的展示面，下方是可检索的功能目录。 因此规范把界面分成三层——画布层（#F4F6FB 灰蓝底）、内容层（白色面 + 1px 边线）、操作层（品牌蓝的按钮、选中与焦点）。 任何新增页面都应先判断内容属于哪一层，再决定用哪一档颜色与圆角。

A一色一职

品牌蓝 #245BFF 只用于主操作、链接、选中项与键盘焦点；智能紫 #6D5EF7 用于知识、AI 与创作类图形；研究青 #078B98 用于研究与数据标识。三者不互相替代，也不用于大面积底色铺满内容区。

B白面承载内容

卡片、表单、弹窗、抽屉统一使用白色内容面 + 1px #E1E7F1 边线，弱阴影可省略。铺满式渐变与深色块只出现在首页轮播这类「展示型」区域。

C状态不靠颜色单独表达

已开通 / 待审批 / 未开通除色差外必须配文字与图标；申请不等于已开通，状态文案与颜色严格对应，不用同一颜色表示两种进度。

D系统字体优先

中文主字体 HarmonyOS Sans SC（缺失时回落 PingFang SC / 微软雅黑），数字与代码使用 Roboto 等宽数字特性。不远程加载字体，保证离线可用。

E两把尺子

间距走 4px 基准（2/4/6/8/10/12/16/20/24/32/40），字号走 12–32px 九阶。新增尺寸必须落在现有档位内，不引入 13.5、18.5 之类的非标值。

F可运行优先

规范中的每个组件都对应可交互实现；组件改版时先改令牌，再改组件，最后同步本文档，避免文档与代码分叉。

03

设计目标

规范不是约束，而是让百舸「长得像百舸」：四个目标贯穿所有页面，界面即规范的最好证明。

Goals

3.1 目标总览

参照成熟企业级规范的表达方式，百舸规范锚定四个目标。统一标准与降本增效面向产品效率， 高效协同面向团队流程，设计延展面向业务增长；右侧是这些目标落地的首页实况—— 品牌蓝标题、提问框、常用功能卡与产品动态，全部由本规范的令牌与组件构成。

统一标准

重新定义数智平台的标准化产品体验，统一品牌形象与设计标准：标志渐变即品牌色，字阶、间距、圆角全部收敛到规范档位，降低决策成本，提高产品迭代效率及质量。

降本增效

基础能力沉淀为可复用组件：按钮、提问框、状态标签、反馈弹层直接取用令牌拼装，减少重复性设计，提高代码复用率，避免重复开发，降低时间及人力成本。

高效协同

设计师与工程师共用同一份令牌语言（--brand-6、--space-*、--radius-*），减少上下游沟通成本，评审有依据、验收有对照，提升团队整体效率。

设计延展

通过设计规范建立，满足组件在不同场景及业务中的延展和扩充：新增智能体、数据系统或前沿工具时只组合既有档位，实现全链路、多场景的高效输出。

3.2 规范与界面的对应关系

界面的每一块区域都能在规范中找到出处：左侧通用问答页体现居中问答布局与输入框规范， 右侧了解平台功能页体现功能卡栅格、图标底色与页签规范。新页面设计时按此方式对照引用，即可保持一致的体验。

字体与字阶

九档字号、四种字重、固定行高；中文与英文同一套节奏。

5.3 字重与用法

400 Regular：正文、说明、表格；500 Medium：按钮、页签、小标题；600 Semibold：页面标题、选中项、卡片标题； 650–700 Bold：仅封面与首页品牌名。同一视图内字重不超过 3 种。中文标题不额外增加字距，仅 24px 以上大标题可收紧 -0.5 ~ -1px。

06

间距系统

4px 基准的 11 档间距，配合 8 的节奏组织区块。

Spacing

所有内外边距、图标与文字间距、栅格间隙都从这 11 个值里取。 2/4/6 用于图标与文字、标签内部；8/10/12 用于控件内部与列表项；16/20/24 用于卡片内边距与列间距； 32/40 用于区块之间与页面留白（首页实际使用 32px 与 48px）。sketch

造型规则

统一 24×24 网格绘制、2px 安全边距、圆头圆角端点。同一视图内不混用「线性 + 面性」两种风格； 业务配图（帆形、立体文档、数据卡）只出现在首页与模块首屏，不进入列表与表单。

颜色规则

线性图标继承 currentColor；业务分类图标按 蓝／紫／青 三色着色，容器底为对应浅色（#E8EFFF / #F0EDFF / #E5F6F5）。 状态图标固定用功能色，不随分类变化。

品牌标志

蓝紫渐变帆形路径，透明底无容器。顶栏 25×30，封面与欢迎区按比例放大；侧栏折叠时不隐藏品牌， 标志四周留白不小于自身高度的 1/4。

装饰图形

浅蓝青光晕、几何线框只做背景层，aria-hidden="true"，不进入阅读顺序，不承载信息，且不得降低其上方文字的对比度。
