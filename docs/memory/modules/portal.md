# 对外门户首页 `portal`

## 当前能力

- `portal.html`（入口）/ `portal.css` / `src/portal.js`。面向客户及合作方介绍船舶行业平台，品牌、主色及证据要求见 `PRODUCT.md`、`DESIGN.md`。入口与控制台 `index.html` 双向可达，控制台顶栏「返回首页」回这里。
- 顶栏五个频道：行业大模型、数智系统、高质量数据集、解决方案、关于我们。频道与部分介绍入口只有待接入提示，不应把宣传按钮描述成已实现工具。首屏轮播的频道使用同一内联示意图，切换改活动信息，键盘可操作；支持按系统减少动态效果偏好调整动画。
- 动态区显示 [门户动态](portal-news.md) 中最新三条，更多动态进入独立列表页。留言咨询横幅、弹窗**只在门户首页**，列表/详情/收藏不出现，详见 [留言咨询](portal-consult.md)。

## 验收锚点

`tests/portal.test.cjs`、`tests/portal-news.test.cjs`、`tests/portal-contact.test.cjs`。覆核入口去向、频道实际行为、同一视觉的主题切换及留言作用范围。没有业务数据时保留示意，不填写真实客户、案例、资质等证据空缺。
