# 控制台与后台外壳 `console-shell`

## 入口与责任

- `portal.html` 的控制台入口打开 `index.html`。控制台白色全宽顶栏：品牌、客服、通知、返回首页、个人中心；左侧是功能导航，右侧通过 iframe 承载内页。品牌回控制台首页，「返回首页」回对外门户。设计基线见 `DESIGN.md`。
- 主路由表 `src/data.js` 的 `navigation`；`src/app.js` 负责路由规范化、权限判断、历史 hash、导航状态和 iframe 生命周期；`src/page-bridge.js` 是独立内页与外壳之间的协议。侧栏有子项的父项只展开/收起，选实际子项进入页面；默认收起，当前深链按需展开父项。`subnav:false` 的文库和数据集在侧栏只展示一个入口，内部仍有子路由。后台入口不出现在用户首页功能目录。
- `src/ui.js` 提供公共 `icon`、`escapeHtml`、知识库选择器等。侧栏用内置线性图标，目录展示图标见 [界面管理](interface-management.md)，二者的视觉和变更范围不同。

## 路由、账户和刷新

- 主外壳复用已挂载内页，对合法来源发送激活、离开和数据；首开需等子页就绪。页面独立打开支持读取子项 hash。切页不能丢失已打开工具标签，内页应该在离开时自行清理模态和计时器。`home-settings` 走后台兼容深链，不在客户端 iframe 展示。
- 临时问句和知识库 ID 只进经过校验的导航消息，不能放在 URL 或作为下一次普通导航参数重播；只允许 `qa` / `对话`。预览路由由外壳白名单和角色菜单共同校验，消息需来自已登记 iframe；仍兼容本地文件的 opaque origin。
- 默认演示账号用功能开通策略；`?iam-user=` 是隔离的账号权限预览，`?iam-account=` 是切换后的演示客户端，后者在 `sessionStorage` 记 `baige.iam.client-account`。受角色约束时从 IAM 的有效菜单决定可见入口；账号停用或权限变化时重算，必要时退回首页。角色菜单计算见 [共享访问控制](access-control.md)，普通功能开通见 [功能权限](function-access.md)。
- 个人菜单在默认账号下有六项：个人中心、权限申请、关于我们、快捷入口设置、后台系统、退出登录。受角色约束的账号隐藏权限申请、快捷设置与后台入口；可从个人中心切换正常演示账号，提交时再查该账号是否可用。客服和通知是顶栏独立按钮；客服中的系统反馈是演示表单，必填、最多 1000 字，内容不实际发送。通知逻辑见 [通知公告](notices.md)。

## 后台壳

- `admin.html` + `admin.js` 承载 iframe 集合。无效 hash 回文件管理；普通管理身份有文库、摆渡、通知公告、门户动态/留言、界面管理和权限相关导航；审核员切换后只展示角色授权审核入口。管理身份的「我的申请」由用户/角色管理触发共享抽屉，旧 `#role-approval` 在管理员下兼容打开抽屉。
- 后台切换管理员/审核员改变本地演示操作者，不等于切换客户端账号。只接受当前管理 iframe 的受支持事件；关闭抽屉把焦点交回来源页。具体审批分流见 [三元审批](iam-approval.md)。

## 验收锚点

`tests/admin-shell.test.cjs`、`tests/sidebar-permissions.test.cjs`、`tests/account-help.test.cjs`、`tests/question-handoff.test.cjs`。重点复核父子菜单、深链/刷新、账号回退、隔离预览、历史和一次性参数、键盘焦点。三套入口同属静态原型，浏览器本地状态不是生产登录或权限强制边界。
