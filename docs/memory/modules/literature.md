# 文献伴读 `literature`

## 上传和历史

- 智能工具「研究辅助 → 文献伴读」及首页同名入口。列表沿用文档翻译的工作区和顶部上传入口，可选或拖放 PDF／DOC／DOCX，每次取第一份，单份不超过 100 MB。
- 「文献伴读历史」是统一 [涉密文件列表](file-audit.md)，保留 PDF/DOC 类型和大小，按文献名即时搜索；原件可用且通过才能下载，已入库或人工审核通过才显示伴读图标。删除须确认，检测中隐藏删除。状态旁的眼睛可打开核查详情，提供悬停说明。
- 上传后先使用 `BaigeTranslateAudit.inspect` 检查正文和文件名，至少呈现一段检测进度。通过为「已入库」、疑似为「涉密可疑」并从详情人工送审，可模拟通过／驳回；失败、拒绝时清除文件对象，审核完成前不能进入伴读。原件保留在当前是可用状态的上传项中。
- 初始 9 项演示数据。工具和记录当前在页面内存。列表底部呈现 `10 / 页`，目前全部匹配行直接渲染，尚未接入分段/翻页。刷新重置演示记录。

## 阅读、侧栏和能力边界

- 通过的行点击伴读进入独立阅读视图，上方返回、文件名和格式。正文两页演示文档，右侧五种页签为伴读、思维导图、翻译、专业术语、问答。新打开时默认首页、伴读标签、当前文献问答欢迎语。正文可用上下页和缩放，导读按钮定位指定页。
- 伴读显示演示概要和按页导读，思维导图显示大纲树；大图、布局及工具栏部分搜索控件为预留演示。翻译可切目标语、看划词指引和演示历史；术语展示企业术语库的使用指引。当前未接入实质划词翻译和术语查询。问答输入后由关键词选择固定回复，保留该次打开的问答记录。
- 通过核查是读取门禁，阅读界面的正文、概要和推荐回答均从本地演示数据生成。上传文件本身可在有原件条件下下载。
