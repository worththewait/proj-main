# 全局个人中心入口

当前实现以文末「左下角入口调整」为准，下面的顶栏方案仅作历史记录。

依据：用户提供的顶部工具栏和头像菜单截图。沿用现有原型与视觉规范，不新增运行依赖。

## 实现范围

- 全局右上角增加 52px 工具栏，包含返回首页与头像按钮，所有模块保持可见。
- 头像点击展开右对齐白色菜单，展示截图账号与角色（演示数据），保留六项名称和顺序：个人中心、通知提醒、关于我们、系统反馈、后台系统、退出登录。
- 个人中心展示演示账号、角色及所属单位；通知显示诚实空态；关于展示已有平台信息；反馈提供类型、内容、校验与演示提交反馈；后台系统显示集成状态；退出登录提供明确的退出演示及返回演示，不影响已有工作区状态。
- 不新增真实认证、消息服务、后台地址或反馈发送，不编造身份、版本和联系方式。
- 菜单支持键盘导航、Escape、外部关闭及焦点恢复；弹窗使用原生 dialog，低高度内部滚动。

## 文件分工

- 入口和说明：index.html、README.md、DESIGN.md。
- 自包含组件：account.css、src/account.js。
- 交互状态只保留当前打开期间；各 iframe 和工具页签保持原有生命周期。
