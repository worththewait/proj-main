# 控制台产品动态 `product-updates`

## 入口与数据

- 前台 `pages/home.html` 中产品动态区，由 `src/pages/home-updates.js` 控制；后台 `admin.html#interface` →「产品动态」。共用 `BaigeHomeConfig.published()`（`src/home-config.js`），保存到 `baige.home-config.v2` 的 `updates` 分段；与对外门户动态发布、全局通知和情报各自独立。
- 日期由发布操作生成，编辑不让选择任意发布日期；标题、日期、正文及白名单内目的地由数据层验证。目的地可空，空时详情无跳转；有目标则先读详情，再选择进入具体功能，「了解平台功能」定位首页目录。旧草稿可读兼容但后台当前没有草稿保存按钮和状态筛选；发布记录可编辑或删除。后台标题查询、分页 10 条，查询重置第一页。

## 浏览规则

- 首页展示最新三条已发布记录（按日期降序），点一条直接看详情，关闭把焦点还给来源。查看全部默认从最近 10 条开始，继续点「加载更早动态」递增，不在弹窗内编号分页。加载保持稳定顺序，每个月只出现一个小标题，不重复条目或月份标题；到末尾有明确提示。
- 全部视图每次只展开一篇全文，可再次点击收起；展开与跳转都重查记录仍有效且已加载。重开全部从首批开始，删除/撤下记录不能通过旧按钮继续浏览或跳转。文字作为纯文本转义；仅内部路由能跳转，继续走原权限策略。首页激活、同源配置变化刷新列表，离开关闭阅读界面。

## 验收锚点

`tests/home-updates.test.cjs`、`tests/home-admin-news.test.cjs`、`tests/home-config.test.cjs`。重点看多于一批、同日排序、跨月加载、关闭重开、编辑发布日、无目的地和撤下状态。
