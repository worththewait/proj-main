# 文档翻译 `document-translation`

## 入口和列表

- 智能工具同名页签、首页入口及热门工具卡。沿用纠错的白色文件列表布局，右上「上传本地文件」也可使用工作区拖放。每次取一个 PDF／DOC／DOCX，单文件不超过 100 MB。当前新上传是中文 → 英文。
- 列为文件名（下方显示大小）、上传时间、文档状态、源语言、目标语言、翻译状态、操作。眼睛看核查。查看结果、下载仅在可用时渲染，删除确认后移除记录。点击搜索/Enter 提交文件名，组合全部／涉密核查／处理中／已完成／处理失败，5 条/页。上传切回全部、首屏并清空搜索。初始演示 27 条。
- 文档状态下附加解析中、翻译中或解析失败。翻译状态只有「翻译成功」「翻译失败」，其他阶段显示「—」；解析失败在文档状态及失败筛选可见。审查可疑、审核中、拒绝和读取失败均不会产生翻译成功状态。

## 顺序与门禁

- 选择文件 → 排入核查 → `BaigeTranslateAudit.inspect` 读正文，检查文件名和正文。读空/失败时停止且显示业务原因。核查通过才可自动进入解析 → 翻译 → 成功。关键词命中须从详情送审，之后才能模拟审核通过，驳回停止处理。没有原件的演示记录即使模拟通过也不能发起新翻译。
- 核查暂存的正文放在以原件对象为键的 WeakMap，`parse` 必须收到通过状态且只能消费一次正文。删除已排队记录后异步部件检查记录仍存在，避免幽灵结果。原件在完成解析、失败检测或驳回后清理。
- 预览仅在核查通过且翻译成功时开启，展示文件信息、翻译方向和 50%–200% 缩放。正文是固定示例。下载按钮仅提示演示无可下载译文。上传、记录和状态存在当前智能工具页面会话，刷新恢复种子数据。
