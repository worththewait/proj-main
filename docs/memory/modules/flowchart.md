# 流程图生成 `flowchart`

## 入口和交互

- 「智能工具 → 研究辅助 → 流程图生成」和首页同名入口。独立目的地、线性图标和后台功能配置项，与思维导图页分开。白色双栏工作区，左侧单一描述框、清空、生成和一键示例（设备报修、材料核查），右侧可滚动预览。
- 输入自然语言或逐行步骤，可粘贴带编号的清单；生成按钮在有输入时可用。出图后输入变化保留上次预览，提示更新后再下载，PNG/SVG 先禁用。更新成功后显示节点数和判断数，恢复下载。换示例时保护有变化的输入，清空重置输入和结果。切页签保留当前挂载页面。
- 规则错误显示在输入下并恢复输入焦点。PNG 本地栅格化，失败提示重试或用 SVG。状态在当前工作区内存，关闭/刷新后无历史。尚未更新的输入会标记页签为未保存。

## 本地解析规则

- 自然语言解析支持分行及常见连接词、箭头、标点，去掉顺序编号而保留正文的数字和小数。最少 2 步、最多 24 节点（判断也算）；动作不超过 40 字，判断不超过 24 字，界面最多输入 2400 字符。
- 自然语言支持一个明确的「如果……就……；否则……」判断，默认两个分支各自结束。有共同后续时需指明「无论结果如何」等合流措辞；仅有肯定分支、条件含糊或含两个判断时给具体补充提示。
- 兼容历史编号输入，当描述含 `|`／`｜` 走 `parseSteps`，支持「是/否指向不同有效步骤」、「下一步」和显式结束。核对顺序号、自指、不可达节点、重复规则与两侧结果。界面优先展示自然语言例子。
- `buildSvg` 从节点及有向边绘制普通步骤、开始/结束、菱形判断、分支标签及回路边，显示和 SVG 导出使用同一内容；嵌入标签按文本转义。当前为确定规则解析和浏览器绘图。
