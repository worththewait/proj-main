# 数据摆渡

- 状态：后管可操作原型，方向为外网导出 JSON → 手动带入内网 → 预览去向 → 确认导入 → 摆渡记录。管理员从 `admin.html#transfer` 进入，`admin.js` 载入 `pages/data-transfer.html?embed=admin`。初始为「内网 · 演示环境」和导入页，带预加载的「外网摆渡示例包」。独立页或后台壳参数 `environment=external` 默认导出，`environment=internal` 默认导入。有显式环境参数时始终显示该环境，两个页签仍可切换。
- 主实现：`src/data-transfer-demo.js`（模拟源/目标、包校验、计划与写入）、`src/pages/data-transfer-export.js`、`src/pages/data-transfer.js`、`src/pages/data-transfer-history.js`、`data-transfer.css`。代码基线 2026-11-17，`c7b7c22`。旧交接文档中「未检出数据摆渡」是立项前状态，当前行为查本记忆和代码。

## 导出选择与包协议

- 来源页签为部门知识库、企业知识库、个人知识库、百舸文库。目录按「分类 → 归属 → 库 → 文件」分组，百舸文库为「管理部门 → 文档」且标示全部公开/有限公开。每类默认展开首归属及首库。当前类别关键字覆盖部门、库名或文件；支持逐文件、按树枝、当前结果全选。切页签或搜索不清已选项，右侧清单汇总全分类，可逐项移除、折叠或清空，零项禁导出。
- 导出为 `百舸数据摆渡-<上海时间戳>.json`，浏览器创建 Blob 下载。包为 `{version:1,items:[{id,name,kind,owner,ownerKey,files:[{name,text}],accessMode?,grants?}]}`。`kind` 为 `department/enterprise/personal/library`；部门库若有人员授权，条目带 `grants:[{personKey,name,department}]`；百舸文库带 `accessMode:public|limited`。局部勾选部门库文件仍随包带该库的整库授权记录。
- 读取本地包和导出均受 5 MiB 限制；导入校验可解析 JSON、版本、非空 items、条目 ID 唯一、四种已知类型、必需归属/名称及附件格式，校验人员授权元数据与文库公开方式。示例文件形式为文本；演示包同时包含无法匹配、无去向、同名、短/长未匹配授权样例。读包失败显示原因，保留先前可用预览。

## 目标匹配、冲突与授权

- 归属按 `ownerKey` 匹配内网模拟字典，来源名称只用于展示。内网没有对应组织、账号或管理部门时该条目无法导入。部门与企业只在同类型同归属下找同名库。部门待选项可选本归属已有库或新建同名库，支持待选列表批量新建；企业待选项只能选本企业已有库；两类均可设跳过。已自动同名匹配项在预览没有改去向按钮。
- 个人按账号自动匹配个人文档目录，仅归该账号。百舸文库按管理部门自动匹配，预览展示源端公开方式；当前写入结构只保留目标目录（ID、名称、种类、归属、文件名、授权键），文库公开方式和原文件文本没有写入真正的文库 store。
- 同一目标以 `trim()+NFC` 文件名判重（包含本批次前序条目），同名跳过、不覆盖。新建部门库的 ID 由类型、归属、规整库名派生，同一批次同归属同名合并。现有文件保留，重复导入不再次增加相同文件和授权。
- 只恢复部门库的人员级整库授权。按 `personKey` 去重、查内网人，已存在的权限保持；未匹配记录为不恢复，不阻断文件。对已有库新增授权也让该人员取得内网原有文档的访问权，预览对此单独标记并可筛选。未匹配名单 3 人以内直列，更多可展开。个人、企业、文库无此恢复流程。
- 预览按分类与归属分组，文库直接显示文件。可按全部、可导入、待选去向、无法导入、同名已存在、已设为跳过、人员未匹配、新增授权覆盖已有文档筛选，并按源/目标、文件、人员查找。摘要同时提示新增、重名、待选、阻塞及授权影响。只有存在可新增文件、新建库或可恢复授权时可确认；确认时未选去向的条目会跳过。

## 导入执行、结果与历史

- 进度轴为「校验摆渡包 → 核对文件与权限 → 写入内网目录」，显示已核对数、进度、耗时、当前文件和最近三份。校验中避免重复导入，正式写入前重算计划；浏览器无法写入则应新增文件变失败。
- 文件结果分已新增／已跳过／无法导入，原因区分显式跳过、无去向、重名、无归属、写入失败。结果按分类、归属、目标库展示，含新建库与恢复授权计数、未恢复人员详情。任务状态 `running/complete/partial/failed/interrupted`，部分跳过、未恢复或成功与失败混合可为部分完成。导入完成后默认优先看成功、其次失败、再看跳过。
- 摆渡记录支持关键字、任务方向、状态筛选及逐文件详情。成功导出可重新下载原 JSON，导出任务也可下载独立 HTML 文件清单；包太大、无可入包文件等失败原因可在历史定位。非 BFCache 的 `pagehide` 持久化处理中任务为已中断，刷新无需声称任务恢复执行。
- `baige.transfer.demo.targets.v1` 保存演示内网文件名/授权键与新库。历史 `baige-data-transfer-history-v1` 保存任务、文件状态与导出包，配额不够时可退回仅保存任务与文件清单；若仍无法保存，本会话内存仍可查看。目录和历史皆为同源浏览器数据。

## 生产边界与回归

- 演示的源、目标、人员及授权全部自带样例，不读写 `BaigeData.knowledgeDirectory`、`BaigeLibraryStore`、个人知识文档或 IAM。真实二进制、文件版本、生产组织身份映射、涉密放行、导入侧复核与发布、签名校验、跨网协议、后台任务恢复和事务由生产规格定义。可参考 `docs/知识库与百舸文库需求交接.md` 第 6 节的问题，不把其中设想当现有功能。
- `tests/admin-shell.test.cjs` 覆盖后管入口和路由。模块手工回归优先验证四类型导出与筛选勾选、同名不覆盖、跨归属阻塞、新建后重复导入、既有库整库授权提示及未匹配折叠、混合结果和历史下载。实现入口 `createPackage / parsePackage / planImport / applyImport` 便于独立验证。
