# AI 悬浮球与快捷设置 `ai-ball`

- `index.html` 外壳全局挂载 `src/ai-ball.js` 与 `ai-ball.css`。仅默认演示账号使用，已有特定角色账号/预览参数时不初始化。拖动记住位置，拖动后不误触展开；视口变化重新约束位置。点击弹出快捷功能；设置入口在个人中心「快捷入口设置」，不是面板内单独卡片。
- 设置从 [控制台首页](home.md) 分类与 [界面管理](interface-management.md) 图标注册表构建，按权限过滤，选择 1–6 项，有旧 ID 兼容。默认对话、文献伴读、百舸写作、文档翻译、纠错校对、PPT生成。配置非法或为空回默认候选，已选条目失去权限不再从面板进入；设置修改后保存才更新。
- 对话快捷入口在悬浮窗使用通用/知识模式、搜索分组知识库、草稿多选及确认。知识列表来自平台 `knowledgeBases`，没有接真实检索；模拟回复与独立会话页不共享消息历史。位置 `qb-pos`、快捷项 `qb-entries`、知识选择 `qb-kbs` 在 `localStorage`；对话消息为窗口内存态。
- 验收 `tests/ai-ball.test.cjs`，另复核拖动与点击分离、窄视口、配置上限和取消、旧 ID、安全的授权过滤及切账号。
