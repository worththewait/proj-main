# 百舸项目功能记忆索引

这里存每个模块的**当前业务规则和实现地图**，供新对话快速恢复上下文。初始盘点对照本地 `c7b7c22`（2026-11-17）；之后以各模块实际核对结果为准。

## 起手读取

1. 找任务的入口、页面名、路由或业务词，只打开下方命中的模块。跨模块时再读相关链接，避免整个目录读入。
2. 根据记忆定位页面、状态层和测试。修改前核对当前分支与目标行为；用户在当前会话最新确认的要求优先。代码和测试是当前原型证据，不能把实现中的缺口当成产品已确认规则。`DESIGN.md` 管视觉基线，历史 PRD 与方案用来补背景。
3. 一旦发现记忆与代码冲突，以实际验证结果陈述，并区分「预期」「已实现」「缺口」。用户要求记忆同步时原位修订，别留下新旧两套有效规则。

## 写入规则

- **完全新建功能**：新页面、工具或能单独完成业务目标的独立流程，在实现并验证后自动写 `modules/<稳定名称>.md`，同步登记本索引。例：把流程图从思维导图拆成独立工具，为流程图建立专档。若初始只有设计，可以在用户要求时单列「已确认、待实现」，不能标成已交付。
- **已有功能修改**：包括增加按钮、改变规则、改布局、修复交互或给已有模块加步骤。按用户当前或长期明确指令写入相应模块；未要求时只读取、核对，不自动改旧记忆。若某条已过时，交付时写明哪个文件需同步。例：文档翻译新增搜索按钮仍归文档翻译；用户明确说「同步记忆」时，在同一任务更新文档翻译记忆。
- **跨模块修改**：规则只有一个主档。共享核查状态写文件核查，文档翻译只记自己的核查 → 解析 → 翻译顺序；审批变更写审批，用户/角色文件只记入口和自己独有的触发条件，并互相链接。旧规则只在需要解释兼容行为或防回归时保留短说明。
- **技术边界**：不复制聊天全文、业务原文、账户样本、联系方式、密码、令牌和上传内容。写仓库相对路径、函数或字段名，避免写易变行号和个人机器路径。不确认的细节写为待核。规则只自动约束读到 `AGENTS.md` 的项目代理；手动编辑不会触发后台同步。

## 单模块记录契约

字段按模块适用性展开，首屏能定位入口及责任。少写设计叙述，多写决策条件和可以验证的行为。

- **入口与责任**：稳定模块 ID、路由/子路由、调用方、参与角色、相邻模块边界。
- **默认与状态**：首屏、默认筛选/排序、状态名及迁移（谁、何时、条件、结果）。复杂流程写 `事件 + 条件 → 状态/动作`，包含取消、刷新、跨页和失败分支。
- **数据与持久层**：关键字段和 ID、数据所有者、存储键、浏览器/会话/内存作用域、与其他模块的联动。
- **不可退化约束**：权限门禁、允许与禁止操作、冲突、默认行为、历史兼容。分清真实实现、演示 mock、用户确认待做及已知差距。
- **代码与验收**：主要 HTML/CSS/JS、适用测试、无法通过自动化证实的关键浏览器链路。重要规则可就近标代码符号；精确数字和枚举必须可核对。
