# 分类归属（部门列表 + 类型库）

- 状态：后台可操作原型。平台指定人员配置，确认即生效、无需审核；部门管理员只在业务页处理本部门文档。入口 `admin.html#category` → `pages/library-category.html?embed=admin&actor=&kind=&by=`。相邻模块 [百舸文库](library.md)、[访问控制](access-control.md)。
- 主实现：`src/library-category-store.js`、`src/pages/library-category.js`、`library-category.css`。代码基线 2026-11-17 定稿（部门列表 + 类型库；此前的“固定八分类表”“按部门分组表”两版已作废）。

## 对象与默认

- **一份类型库 + 一张部门列表**：类型库管类型的增删；部门行的「类型管理」从同一份类型库多选，勾选即由本部门负责。
- 初始八类型：智库成果、船舶标准、行业专利、三方研报、规则规范、专业书籍、期刊论文、其他。首次进入沿用既有分工：经研中心（经济研究中心）负责智库成果、三方研报；标准中心（船级社规范所）负责船舶标准；知产中心（技术经济中心）负责行业专利；数智中心（情报研究所）负责规则规范、专业书籍、期刊论文、其他；动力研究院与国际航运研究中心暂不负责类型。
- 页面：标题下「部门列表」面板，右上「类型管理」（类型库）；表格三列（部门、负责类型、操作）。负责类型以浅蓝标签展示，没有则显示「暂未负责类型」；行尾「类型管理」打开多选框。有未分配类型时，表格末尾多一行「未分配类型」，灰色标签，右侧提示「在部门中勾选」。底部一行汇总（共 N 个类型、已分配、未分配）。
- 表格下方「最近调整」显示最近三条：新增类型、删除类型、交由某部门负责、改为未分配、单个类型调整。

## 两个弹窗

- **类型管理（全局）**：输入框 + 「添加」新增类型（2–12 字、不可重名），列表逐行显示「类型名 / 负责部门 / 删除」。删除前确认；该类型下还有文档时拒绝并提示「「X」下还有 N 篇文档，暂不能删除；可先调整文档类型」。
- **部门类型管理**：标题为「某部门 · 类型管理」，勾选框来自类型库（两列），每项右侧灰字提示「现由 某部门 负责」或「未分配」，已勾选项为蓝框蓝底。保存即提交多选结果：勾选的归本部门（原属其他部门的会自动转移），取消勾选的转为未分配。
- 两个弹窗都带 `expectedVersion`，别人先改过时提示「类型配置已被其他配置人员修改，请刷新后再确认。」。

## 权限与生效范围

- 配置入口与保存共用一个平台级权限：`canConfigure()` 只认平台指定人员（演示身份 `kind === "admin"` 或 id 在 `PLATFORM_EDITORS`）。无权限时保留标题与说明，只显示「没有配置权限」，面板隐藏；后台导航对审核员隐藏。
- 按类型整体生效，不逐篇改文档：文件管理按上传件的类型归属过滤，权限管理按上传件与爬虫文档过滤，前台归属权限按当前归属计算。原部门若已无负责类型，文件管理空态显示「本部门暂无负责分类」，仍可作为授权对象。
- 上传向导的分类选项、管理端的「管理部门」下拉都来自同一份映射；新接手的部门自动出现在下拉中（四个原有视角保持顺序，新部门追加在后）。
- 类型库是权威来源：`BaigeLibraryStore.categories`、`managerTypes(dept)`、前台 `pages/library.js` 的分类导航与检索下拉都以 `store.types()` 为准，新增的类型立即出现，删除的类型立即消失。

## 未分配类型

- 允许类型没有负责部门（部门多选里取消勾选即转为未分配）。未分配类型不出现在上传向导、文件管理、权限管理与管理部门下拉中。
- 已有文档不丢：`normalizeDoc` 里 `ownerDept = ownerFor(category) || previousOwner`，未分配类型下的存量文档仍由原部门管理、保留 4 级，直到该类型被分配给新部门。

## 数据与持久层

- 键 `baige.library.category-owner.v1`：`{version, types:[名称], owners:{类型:部门|""}, changes:[{action:"create"|"delete"|"assign"|"unassign"|"move", at, by, category, from, to}], updatedAt, updatedBy}`。
- 读取兼容旧结构（只有 `owners`）：以种子为底、把自定义类型追加在后；新结构里 `types` 为准，删除过的类型不会再回来。
- 保存写库后派发 `baige:library-category`；文库数据层监听该事件与其他标签页 `storage`，丢弃文档缓存，保证旧页面再提交时按最新分工判断。
- 变更记录保留最近 50 条；`changes(limit)` 返回倒序。

## 权限计算（不可退化）

- 文档归属由类型映射推导（`ownerFor(category)`），不写死。归属部门恒为 4 级；归属变化时只收回「因归属自动获得」的 4 级（降为公开方式对应的普通等级 3），显式单独授予的部门 4 级保留（`setPermissions` 写作 `explicitDept`）。
- 有限公开文档交接后：原部门转为试读（`isTrialAccess` 为真），新部门全文与下载；公开方式、单独授权、涉密与解析状态不变。
- 验收锚点：`tests/library-category.test.cjs` 覆盖部门列表页面、类型库增删、名称校验、部门多选（勾选转移 / 取消转未分配）、未分配存量文档、版本冲突、权限交接与显式授权保留、管理范围跟随；`tests/library-store.test.cjs` 覆盖原有归属与权限规则。
