# 百舸问答 `qa`

## 入口和默认

- 控制台「百舸问答 → 对话」和首页快速提问共用 `pages/qa.html`。实际对话逻辑文件名是 `src/pages/home.js`，首页代码在另一个文件 `src/pages/home-dashboard.js`。姐妹入口「智能问数」是正在集成页，会隐藏对话动作、关侧栏并中断生成。
- 欢迎页含建议问题、换一批、引用示例。建议只填入输入区。左上历史、新建图标，输入区左侧通用问答/知识问答/联网搜索，右侧发送/停止。无附件上传。首开或刷新两侧都收起；历史在左、原文在右并互斥展开，关闭时恢复焦点。

## 发问与会话

- `src/qa-session.js` 管理通用/知识模式和已选与草稿范围。`src/data.js` 的 `knowledgeBases` 是八项演示来源（不等同资料首页 `knowledgeDirectory`）。行业、企业、部门可跨分类选择，搜索不清空隐藏项，空选或失效 ID 不生效；取消保留上一次确认的选择。切通用不携带来源，但保存选择供切回；历史旧记录在知识模式却没有有效 ID 时提示重新选择。
- 联网搜索为独立演示开关，不会发起检索；知识模式和通用模式都可以切换。首页问句经外壳校验，只在「对话」消费一次，按是否附有效知识库 ID 决定模式。问句不入 URL。输入法确认和 Shift+Enter 不发送，送出后进入对话布局；生成中拒绝再次发问，主动停止、切页或切会话时保留已输出文本。
- 回复逐字模拟（35ms 步进），无真实模型。消息区近底部才自动跟随；向上阅读时停止跟随并显示回到最新。滚动只调整消息区，输入区、侧栏布局改变后也遵守跟随状态。
- 本地 `baige.qa.history.v1` 保存会话 ID、标题、时间、消息、模式、知识库 ID、联网状态；按本地日期分组，支持搜索和逐条确认删除。新建清除当前会话但不删除其他记录；换会话恢复其设置与消息；刷新读历史而不自动打开侧栏；中断的消息只恢复已持久化的实际文本。

## 引用与原文

- `src/conversation-data.js` 提供演示问答、引用号、资料卡、原文页面；正文引用、参考资料卡点击打开对应资料与页码。支持收起/扩展、翻页、80–150% 缩放；打开历史可临时收起原文并保留文档，切换会话清除上一个会话的原文状态。示例问答、引用和随后的追问一起保存在历史；普通回复不虚构来源。
