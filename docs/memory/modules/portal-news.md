# 门户最新动态与动态发布 `portal-news`

## 入口与存储

- `portal.html` 首页卡片、`portal-news.html` 最新动态、`portal-news-detail.html` 详情；`admin.html#portal-news` → `pages/portal-news-admin.html` 动态发布。`src/portal-news.js` 管前台，`src/portal-news-admin.js` 管后管，`BaigePortalNewsStore` 在 `src/portal-news-store.js` 读写 `baige.portal.news.v1`。不要混用控制台产品动态和全站通知公告的 store。
- 标签固定七种：通知公告、行业动态、政策法规、智库成果、研究报告、其他、活动报名。旧自定义标签读取时迁移到七类，未识别归其他。标签是筛选用枚举，公告类型决定是否开放活动报名，两个字段分开。

## 浏览与发布

- 首页三条按最新发表顺序；更多动态按置顶优先和数据层排序渲染。横排分类点即切换，搜索框通过「搜索」或回车才提交关键词，筛的是标题；切分类保留已提交关键词，不偷用尚未提交的草稿。分类和关键词写 hash 的 `tag/q`，从详情返回列表恢复条件。详情入口携带 `id` 与来源 `from`，首页来源回首页；未匹配 ID 时当前实现会有最新一条的回退。收藏单独见 [门户收藏](portal-favorites.md)。
- 后台按标题、类型、状态和发布日期范围筛选，编辑在抽屉内。字段有标题（最多 50 字）、七类标签、公告内容（富文本）、类型、置顶、序号、可选封面和草稿/已发布。标题、标签、正文必填；发布进入门户，草稿不进入普通列表/首页。已有记录编辑保留原发布时间，ID 自增；删除确认后前台列表同步移除。详情直接读取 `store.find`，不能把列表的已发布筛选视为生产端访问控制。
- 「活动报名公告」详情出现立即报名。活动名只读；姓名、11 位手机号、邮箱必填，性别、单位、部门、职务/职称及 200 字备注可选。验证成功关闭并提醒，原型无真实报名保存或短信发送。

## 验收锚点

`tests/portal-news.test.cjs`、`tests/portal-news-admin.test.cjs`。回归分类当场生效/文本显式提交、详情返回恢复筛选、发布前后、删除与原始时间保留、活动表单和同源数据。新内容须在生产接入前独立处理服务端发布可见性与富文本校验。
